## 📌 About the Project  

The **Financial Website** is a static yet dynamic site built using **HTML, CSS, JavaScript, and PHP**. It provides users with financial-related services and features a secure login/logout system. **PHP** is used for backend functionalities and database connections, ensuring a seamless user experience.  

### 🚀 Features  

✅ **Fully Responsive Design** – Works smoothly on all devices.  
✅ **Secure Login & Logout System** – User authentication for personalized access.  
✅ **JavaScript Animations** – Integrated **GSAP ScrollTrigger** for smooth scrolling effects.  
✅ **Database Connectivity** – Powered by **PHP** for handling user data.  
✅ **User Access Control** – Logged-in users can access all services.  

## 🔧 Technologies Used  

- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** PHP  
- **Animations:** GSAP, ScrollTrigger  
- **Database:** MySQL  

## 📜 How to Use  

1. **Clone the repository:**  
   ```sh
   git clone https://github.com/sujit-patel/Financial-Website.git
   ```
2. **Set up the database in MySQL.**
3. **Run the project on a local server (XAMPP, WAMP, etc.).**
4. **Login to access all services!**
